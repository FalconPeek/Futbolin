Superficie con borde y título opcional para agrupar contenido.

**Cuándo:** cada bloque de la home del grupo (acciones pendientes, próximos partidos, feed), resúmenes de partido y paneles del perfil.

**Qué provee quien lo usa:** `children`, y opcionalmente `title`, `subtitle` y `action` (un Button `ghost` o un Badge).

**Reglas**
- Padding `space-4`, radio `radius-lg`, separación entre tarjetas `space-3`–`space-4`.
- No anides tarjetas dentro de tarjetas; usá divisores `border`.
